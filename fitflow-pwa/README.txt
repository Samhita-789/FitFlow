FitFlow PWA
1. Upload this whole folder to any HTTPS host (Netlify Drop, Vercel, GitHub Pages, Cloudflare Pages).
2. Open the URL on your phone once while online.
3. Android/Chrome: menu > Install app. iPhone/Safari: Share > Add to Home Screen.
Works offline after the first visit. Test locally: python3 -m http.server 8000 (localhost counts as secure).
